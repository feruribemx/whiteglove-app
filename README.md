# WhiteGlove App

App interna de operación para WhiteGlove Professional Services.

## Desarrollo local (opcional)

Si algún día quieres correrla en tu computadora:

```bash
npm install
npm run dev
```

## Deployment

Se despliega automáticamente en Vercel al hacer push a la rama principal.
